# Guang Quan Tan (William) · Portfolio

Public portfolio: https://williamtangq.github.io/

A static, responsive portfolio focused on early-career Business / Systems Analyst roles. Four featured cases connect client onboarding, decision modelling, UX research and enterprise systems; six supporting cases cover healthcare, prototypes, text analytics, governance and SQL.

## Evidence policy

Public case summaries are readable without repository access. Individual contributions are distinguished from team delivery. Personal sketches and model charts are attributed; newly drawn workflow summaries are not presented as application screenshots. Client source documents and detailed restricted evidence are not copied into this public repository.

## Verification

Run `node scripts/check-portfolio.mjs` for local links, fragment destinations, page structure and JavaScript syntax. Browser QA covers desktop and mobile layout, project filters, navigation and new case destinations. GitHub Pages publishes the main branch through its existing configuration.

See docs/recruiter-review.md for the recruitment-lens rationale. Resume variants preserve the existing employment/contact details and update project emphasis. The cover-letter builder is a local drafting aid.
